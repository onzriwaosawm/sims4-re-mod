## Overview

The RE Mod (Relationship Enhancement) overhauls The Sims 4's social and relationship systems with nuanced friendship depth tiers, an active rivalry mechanic where rivals spread rumors, realistic breakup consequence moodlets, and context-aware jealousy events during group social interactions — creating emotionally richer and more dramatic gameplay.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **The Sims 4 RE Mod** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Friendship Tiers** | Multiple friendship depth levels with distinct interaction options per tier |
| **Rivalry System** | Rival Sims actively seek negative interactions and spread social rumors |
| **Breakup Consequences** | Long-duration negative moodlets and awkward NPC re-encounters |
| **Jealousy Events** | Context-triggered jealousy reactions during group social situations |
